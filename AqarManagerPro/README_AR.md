# AqarManagerPro — إصدار أولي لإدارة العقارات

المشروع Python + PySide6 + SQLite. العملاء والعقارات والعقود، إضافة وتعديل وحذف وبحث، طباعة الجدول الظاهر، PDF ونسخ احتياطي. القيم المالية تحفظ بوحدات القرش. الربط بين السجلات يتم بإدخال أرقام العملاء والعقارات الظاهرة بالجداول. تقارير العقود ليست صياغة عقد قانوني.

## حالة التسليم
ملفات EXE تنتج من البناء. لا يعتمد نجاحها إلا على سجل GitHub Actions ونتائج الاختبارات المرفقة. راجع VALIDATION.md لنتائج الاختبار الفعلية. إصدار x64 مستهدف لـ Windows 10/11؛ يلزم اختبار الجهازين قبل التسليم التجاري. لا يوجد حساب GitHub متصل ولم يتم تشغيل Actions من هنا.

## الحصول على EXE دون إعداد بيئة برمجية على جهاز العميل
1. أنشئ مستودع GitHub خاصًا وارفع محتويات المجلد بما فيها `.github/workflows/windows.yml` (يمكن رفع ZIP عبر GitHub Desktop بعد فكّه).
2. جهّز مفتاح البائع كما في القسم التالي قبل البناء. المفتاح العام فقط يرفع إلى المستودع.
3. افتح Actions ثم Build Windows distribution ثم Run workflow.
4. بعد نجاح التنفيذ افتح العملية وحمّل artifact باسم AqarManagerPro-Windows-x64.
5. فك ZIP الناتج: ملف AqarManagerPro_Setup.exe هو ما تسلمه للعميل. توجد أيضًا نسخة Portable داخل ZIP؛ يجب إبقاء مجلدها كاملًا مع EXE ومكتباته.
6. في مجلد البناء تجد source-test.json وfrozen-test.json كدليل اختبارات العملية. إذا فشل البناء، راجع سجل الخطوة وfailure-diagnostics.

## مفتاح التفعيل — للبائع فقط
مرة واحدة على جهاز البائع المثبت عليه Python ومكتبة cryptography:
```
python -m pip install cryptography==44.0.2
python tools/license_tool.py init --private C:/SellerKeys/aqar.private
```
أنشئ المجلد C:/SellerKeys أولًا. احتفظ بالمفتاح الخاص خارج المشروع ولا ترسله للعميل أو GitHub. احفظ نسخة احتياطية منه؛ ضياعه يمنع إصدار مفاتيح متوافقة مع النسخ المباعة. ملف assets/public_key.bin ينتج تلقائيًا. لا تبدله بعد البيع.

العميل يرسل رمز الجهاز الظاهر على شاشة التفعيل. لإصدار المفتاح:
```
python tools/license_tool.py issue --private C:/SellerKeys/aqar.private --machine DEVICE_CODE --customer "اسم العميل"
```
أرسل ناتج الأمر للعميل ليلصقه في نافذة التفعيل. التفعيل محلي بلا إنترنت، مرتبط بمعرّف Windows. لا توجد مفاتيح عامة جاهزة ولا مفتاح خاص داخل التوزيع. التوقيع يمنع تزوير المفتاح، لكنه لا يمنع تعديل البرنامج من مهاجم متخصص.

## البناء على Windows محليًا
ثبّت Python 3.11 x64 وInno Setup 6 على جهاز البناء فقط، ثم جهز مفتاح البائع وشغّل PowerShell:
```
powershell -ExecutionPolicy Bypass -File build_windows.ps1
```
المخرجات في release. EXE في dist/AqarManagerPro. العميل لا يحتاج Python. الملف المثبت يضم Qt ومكتبات الطباعة والخط والأيقونة ويضيف اختصار سطح المكتب.

## البيانات والتحديث
البيانات ومفتاح التفعيل في `%LOCALAPPDATA%/AqarManagerPro`، مستقلان عن `%LOCALAPPDATA%/Programs/AqarManagerPro` مجلد البرنامج. التحديث وإزالة البرنامج لا يمسحان البيانات. هذه بيانات كل مستخدم Windows على حدة. استخدم زر النسخة الاحتياطية دوريًا؛ للاستعادة أغلق البرنامج واستبدل aqar.sqlite3 بالنسخة الصحيحة بعد الاحتفاظ بنسخة من الملف الحالي. لا توجد استعادة تلقائية في هذه النسخة.

## التحقق قبل بيع النسخة
على Windows 10 و11 x64: تثبيت على حساب عادي دون Python، فتح التفعيل ورفض مفتاح جهاز مختلف وقبول الصحيح، إضافة وتعديل عميل وعقار وعقد، إعادة الفتح والتأكد من بقاء البيانات، تجربة الطباعة على طابعة حقيقية وPDF، ترقية ثم إزالة وإعادة تثبيت والتحقق من البيانات، والتأكد من الاختصار. Actions يختبر قاعدة البيانات والتوقيع وPDF وإنشاء نافذة الطباعة وفتح الواجهة على Windows Server 2022؛ لا يثبت عمل طابعة فعلية أو Windows 10/11. البرنامج غير موقع رقميًا وقد يظهر تحذير Windows؛ التوقيع يحتاج شهادة يملكها البائع.

## تراخيص الطرف الثالث
الخط DejaVu Sans مرفق مع ترخيصه. PySide6/Qt تستخدم وفق LGPLv3؛ لا تحذف ملفات تراخيص المكتبات من التوزيع. راجع إشعارات الحزم قبل التوزيع التجاري. أيقونة المشروع أصلية.

## أداة البائع الرسومية
بعد البناء حمّل AqarManagerPro-Seller-Tool.zip للبائع فقط، فكّه كاملًا وشغّل AqarSellerLicenseTool.exe. اختر aqar.private من الحزمة الخاصة ثم أدخل رمز جهاز العميل واسمه وانسخ مفتاح التفعيل. لا يحتاج تشغيل الأداة Python. لا تسلّم أداة البائع أو المفتاح الخاص للعميل.

المفتاح العام في هذا المشروع جاهز، والمفتاح الخاص الموافق له في حزمة البائع الخاصة. لا تشغّل init على هذا المشروع ولا تغيّر المفتاح العام بعد البناء. تشغيل init في الأمثلة مخصص فقط لإنشاء مشروع جديد مستقل.
